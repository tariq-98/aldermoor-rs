# Aldermoor (Rust)

A real-time fantasy RPG for Apple-silicon Macs: the Rust rebuild of Aldermoor. Start with
[docs/PLAN.md](docs/PLAN.md).

The first native Metal client now loads the art catalogue and runs against the simulation:

```sh
scripts/run_client.sh
```

See [docs/RENDERER.md](docs/RENDERER.md) for controls, asset review captures, tests and measured
performance limits.
